1Qué es un agente

Un agente de IA no es magia ni un chatbot más. Es un modelo de lenguaje (LLM) al que le damos herramientas y lo dejamos trabajar en un bucle: el modelo decide qué herramienta usar, nosotros ejecutamos esa función de verdad, le devolvemos el resultado, y repite hasta terminar la tarea.

MODELO
decide
⇄
LOOP
orquesta
⇄
HERRAMIENTAS
ejecutan R

Esa es la diferencia con el autocompletar: el agente actúa. Puede cargar un CSV, correr una regresión, ver el error que salió y corregirse. En este taller construimos exactamente eso, con tus funciones de R como herramientas.

Las 3 piezas, en archivos:
PiezaEn nuestro harness de RQué es
Modelouna línea de configel LLM (local o en la nube)
Herramientastools.Rtus funciones de R
Alma / reglasalma.mdquién es y cómo se comporta
Loopagente.Rel motor (no lo tocas)

2Modelos locales con Ollama

Ollama es una app gratis que te deja descargar y correr modelos de lenguaje en tu propia máquina. Dos cosas lo hacen ideal para empezar:

  • Privado y sin internet. El modelo corre local; tus datos nunca salen de tu PC. Útil con datos clínicos sensibles, o en un avión sin wifi.
  • Interfaz tipo ChatGPT, gratis. Con un comando tienes un chat en la terminal (y apps gráficas si quieres), sin pagar ni crear cuenta.

2.1 Instalar Ollama

macOS / Windows Descarga el instalador desde ollama.com/download y ábrelo. En Mac también: brew install ollama.
Linux 
curl -fsSL https://ollama.com/install.sh | sh

2.2 Descargar un modelo

Elige según tu laptop. Para el taller recomendamos qwen2.5:3b (corre en casi cualquier PC):

ollama pull qwen2.5:3b
ModeloTamañoRAM sugeridaNotas
qwen2.5:3b~2 GB8 GBDefault. Rápido, buen tool calling.
qwen3:4b~2.6 GB8–16 GBRazona mejor, algo más lento.

2.3 Probarlo como un ChatGPT local

Para chatear directo en la terminal (sin nada de R todavía):

ollama run qwen2.5:3b

Escribe tu pregunta y listo. Escribe /bye para salir. Esto solo es para que veas el modelo vivo; el agente de verdad lo armamos abajo.

Nota: la primera vez que usas un modelo, Ollama lo carga en memoria y la primera respuesta tarda unos segundos. Las siguientes son rápidas.

3Correr el agente en R

El agente vive en R usando el paquete ellmer (de Posit), que conecta R con cualquier modelo: local (Ollama) o en la nube (Claude, etc.).

  1. Instala R desde cran.r-project.org (opcional pero cómodo: RStudio).
  2. Instala ellmer en R: 
    install.packages("ellmer")
  3. Descarga este repositorio (botón verde Code → Download ZIP en GitHub, o git clone) y descomprímelo.
  4. Corre el agente completo. En R/RStudio, dentro de la carpeta 02-esqueleto-completo: 
    source("agente.R")
preguntar("Hazme la tabla 1 comparando por tratamiento, con valores p")
preguntar("¿Qué variables se asocian con mayor mortalidad?")

También puedes correrlo como chat en la terminal:

cd 02-esqueleto-completo
Rscript agente.R

El agente cargará cohorte.csv, llamará a tus funciones de R (crear_tabla, ajustar_modelo) y te interpretará el resultado. La Tabla 1 queda guardada en tabla.html.

4Personalizar tu propio agente

Aquí está lo bueno: pasar del esqueleto vacío al que funciona es solo llenar dos archivos. El motor (agente.R) no se toca.

El alma (alma.md)

Quién es el agente y sus reglas. Es texto plano:

Eres Rho, un asistente de análisis en R especializado en epidemiología.
Tienes herramientas que ejecutan código R de verdad.
Reglas:
 - Usa siempre tus herramientas; nunca inventes números.
 - Carga los datos antes de analizarlos.
 - Responde en español, claro y conciso.

Las herramientas (tools.R)

Cada herramienta es una función de R + una descripción para el modelo. Ejemplo real de este repo (tabla con gtsummary e instalación automática):

crear_tabla <- function(comparar_por = NULL) {
  if (!requireNamespace("gtsummary", quietly = TRUE))
    install.packages("gtsummary")          # se instala sola si falta
  library(gtsummary)
  datos <- obtener_datos()
  if (is.null(comparar_por)) tbl <- tbl_summary(datos)
  else tbl <- tbl_summary(datos, by = all_of(comparar_por)) |> add_p()  # tabla comparativa + p
  tbl |> as_tibble() |> knitr::kable() |> paste(collapse = "\n")
}

tool_tabla <- tool(
  crear_tabla,
  "Crea una Tabla 1 con gtsummary. Si se indica comparar_por, agrega valores p.",
  arguments = list(
    comparar_por = type_string("Variable de grupo (p.ej. 'tratamiento').", required = FALSE)
  )
)

Registras tus funciones en la lista TOOLS y el agente ya puede usarlas. Así lo adaptas a tus librerías y tu flujo de trabajo.

Tip: haz tus herramientas robustas. En este repo, si el agente olvida cargar los datos, la herramienta los carga sola. Un modelo pequeño se equivoca más; una tool a prueba de errores salva el día.

5Claude Code CLI: los superpoderes

El harness casero enseña el concepto. Para trabajo real, un agente "de fábrica" como Claude Code te da el loop, las herramientas (leer/escribir archivos, correr comandos) y un modelo mucho más capaz, sin que programes nada.

  1. Instálalo: 
    # opción nativa
curl -fsSL https://claude.com/install.sh | bash
# o con npm
npm install -g @anthropic-ai/claude-code
  2. Entra a la carpeta 03-claude-code y ejecuta claude.
  3. Pídele lo mismo: "Hazme la tabla 1 comparando por tratamiento, con valores p."

Verás el mismo esqueleto, con otro vestido:

Harness casero (carpetas 01–02)Claude Code (carpeta 03)
alma.mdCLAUDE.md
tools.R.claude/skills/ + tools nativas
agente.R (el loop)viene incluido
modelo localClaude (nube)

El concepto es idéntico. Cambia el pulido y la fiabilidad.

6Otras herramientas

Antigravity Google

Un IDE agéntico construido alrededor de los modelos Gemini: el agente planifica, escribe y ejecuta código, y tú supervisas. Es la apuesta de Google en la misma dirección que Claude Code. antigravity.google

Visual Studio Code + extensiones

Si prefieres un editor gráfico, puedes meter el agente dentro de VS Code:

  • Cline y Continue: agentes open-source que funcionan con modelos locales (Ollama) o en la nube, directo en el editor.
  • GitHub Copilot: el asistente integrado de Microsoft.

Todos son variaciones de lo mismo: modelo + herramientas + loop, dentro del editor.

7Local vs. nube: cuándo usar cuál

Modelo local (Ollama)Nube (Claude Code)
PrivacidadTotal: nada sale de tu PCLos datos van a un servidor
CostoGratisDe pago / con límites
InternetNo requiereRequiere
CapacidadBuena en tareas cortas (1–2 pasos)Muy alta, tareas largas
Ideal paraDatos sensibles, aprender, offlineTrabajo complejo y reproducible

La buena noticia: es el mismo esqueleto. Empiezas local para aprender y por privacidad, y cambias a la nube cuando necesitas más potencia — a veces con solo cambiar una línea.
